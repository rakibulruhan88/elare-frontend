Project Name: Elare (MERN Stack E-Commerce)

Frontend Framework: React.js (Vite)

Styling & UI: Tailwind CSS

API Communication: Axios

🛠️ 1. Core Technologies & Libraries
The frontend architecture utilizes modern, industry-standard libraries to ensure a highly scalable and performant user interface:

React Router DOM: Implemented for seamless Single Page Application (SPA) routing, allowing dynamic navigation without page reloads.

Tailwind CSS: Utilized for a utility-first styling approach, ensuring a highly customizable, modern, and 100% responsive user interface.

Axios: Handles asynchronous HTTP requests to interact with the backend Node.js/Express REST APIs securely.

Framer Motion: Integrated to provide fluid, advanced UI animations (e.g., page transitions, modal sliding) for a premium user experience.

React Icons (react-icons/md): Used for lightweight, scalable Material Design vector icons across the application.

🔀 3. Routing & Navigation Architecture
The application routing is strictly segregated into three distinct access levels to maintain security and flow:

A. Public Routes (Accessible to all visitors)
/ ➔ HomeScreen: Landing page featuring hero banners and featured products.

/shop ➔ ShopScreen: Comprehensive catalog with advanced client-side filtering.

/product/:id ➔ ProductScreen: Detailed product view with descriptions, stock status, and "Add to Cart" functionality.

/cart ➔ CartScreen: Shopping cart management with dynamic subtotal calculations.

/contact ➔ ContactScreen: Dynamic communication form integrated with backend APIs.

/login & /register ➔ Auth Screens: User authentication and registration portals.

B. Protected Routes (Requires Authentication)
/shipping ➔ ShippingScreen: Captures user delivery details.

/payment ➔ PaymentScreen: Payment gateway selection (e.g., COD, Stripe).

/placeorder ➔ PlaceOrderScreen: Final checkout summary and order execution.

/order/:id ➔ OrderScreen: Post-purchase invoice and real-time delivery status tracking.

C. Admin Routes (Requires Admin Authorization)
/admin ➔ AdminDashboard: Business analytics overview.

/admin/products ➔ ProductListScreen: CRUD operations for inventory management.

/admin/orders ➔ OrderListScreen: Centralized order management and status dispatching.

/admin/customers ➔ CustomerListScreen: Registered user database overview.

/admin/messages ➔ AdminContactScreen: Tabular view of customer inquiries with unread status indicators.

/admin/messages/:id ➔ AdminMessageScreen: Detailed message view with deletion capabilities and integrated mailto: automated email replies.

🖥️ 4. Core Features & UI Mechanisms
1. Advanced Shop Catalog & Filtering:

Implements dynamic client-side pagination (20 items per page).

Features a sophisticated filtering system: multi-category selection, maximum price slider, availability toggles, and sorting algorithms (Price/Newest).

Responsive Strategy: Utilizes a sticky sidebar for desktop environments and an app-like animated 'Bottom Sheet Modal' for mobile devices.

2. Contact & Admin Communication Workflow:

Real-time form validation and submission feedback with loading spinners.

The Admin Message Panel uses visual indicators (Blue Dots) for unread messages.

Features a frictionless reply mechanism triggering native email clients pre-filled with the customer's subject and address.

🔒 5. State Management & Security
To maintain a lightweight footprint, the application utilizes native React state management combined with browser storage APIs:

State Hooks (useState, useEffect): Manages real-time API payloads, UI loading states, and error handling dynamically.

Authentication Security (JWT): User sessions and JSON Web Tokens (JWT) are securely stored. API calls to protected backend routes (like order creation or admin functions) automatically attach this token to the Authorization header as a Bearer token.

Persistent Cart & Shipping Data: localStorage is utilized to persist cart items and shipping addresses, preventing data loss upon page reloads and ensuring a seamless user experience.
